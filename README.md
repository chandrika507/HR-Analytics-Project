# HR-Analytics-Project
HR Analytics project using Power BI to analyze employee demographics, hiring trends, gender distribution, department-wise workforce, and workforce insights to support data-driven decision-making.

**HR Workforce Analytics Dashboard | Power BI**

 **Project Overview**
This project focuses on analyzing employee data and creating an interactive HR Analytics Dashboard using Microsoft Power BI. The dashboard provides meaningful insights into workforce demographics, employee distribution, and hiring trends to support data-driven HR decisions.

 **Objectives**
- Analyze total employee count and average employee age.
- Understand remote and headquarters work distribution.
- Analyze gender and race representation.
- Identify employee distribution across departments and states.
- Track yearly hiring trends.

**Dashboard Features**
- **KPI Cards:** Total Employees, Average Employee Age, Remote Work %, and Headquarters Worker %.
- **Department Analysis:** Employee distribution by department.
- **State Analysis:** State-wise employee distribution.
- **Gender Analysis:** Male, Female, and Non-Conforming representation.
- **Race Analysis:** Race-wise employee distribution.
- **Hiring Trend:** Year-wise hiring analysis.

**Tools & Technologies**
- Microsoft Power BI
- Power Query
- Data Visualization
- Data Analysis

 **Key Findings**
- Total workforce is approximately 1,000 employees.
- Average employee age is 38.55 years.
- 25% of employees work remotely.
- 75% of employees work at headquarters.
- Male employees represent 53.1%, female employees 44%, and non-conforming employees 2.9%.
- Employee distribution varies across departments and states.

 **Conclusion**
This project demonstrates how Power BI can transform employee data into meaningful visual insights. The interactive dashboard helps understand workforce patterns, employee demographics, and hiring trends, supporting better HR planning and data-driven decision-making.
